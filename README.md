# Fourier Garden

**푸리에 변환**을 배우고, 사인파를 쌓아 나만의 소리를 만드는 웹 실험실입니다.
설치나 빌드 없이 브라우저에서 바로 실행됩니다.

## 학습 순서

처음 접속하면 1단계부터 시작하고, 다시 들어오면 마지막으로 보던 단계가 열립니다.

1. **푸리에 변환** — 같은 소리를 시간 영역(파형)과 주파수 영역(스펙트럼)으로 비교하고,
   수수께끼 소리에 탐지 사인을 곱해 평균 내는 방식으로 숨은 사인을 찾아 스펙트럼을 완성합니다.
2. **사각파 · 삼각파 · 톱니파** — 세 기본 파형을 들으며 스펙트럼을 비교하고,
   사인을 하나씩 쌓아 파형이 만들어지는 과정과 깁스 현상, 위상의 역할을 확인합니다.
3. **소리 맞히기 미션** — 목표 소리를 듣고 사인을 조합해 유사도 80~90% 이상을 만들면 성공입니다.
   유사도는 배음별 세기(dB) 차이로 계산하며, 위상과 엔벨로프는 채점하지 않습니다.
4. **나만의 소리** — 사인 오실레이터(배율, 레벨, 디튠, 위상), A/B 두 개의 ADSR 엔벨로프,
   6밴드 EQ와 실시간 스펙트럼을 모두 써서 자유롭게 소리를 만듭니다.

만든 소리와 진행 기록은 각자의 브라우저에만 저장됩니다.

제작: 여광재 (온양고등학교)

## 실행

`index.html`을 브라우저에서 열면 됩니다. 3·4단계에서는 컴퓨터 키보드(흰 건반 A S D F…, 검은 건반 W E T Y U…)나 화면 건반으로 연주합니다.
주소 끝에 `#learn`, `#waves`, `#missions`, `#studio`를 붙이면 해당 단계로 바로 열립니다.

## 기술

- Web Audio API (OscillatorNode, PeriodicWave, BiquadFilterNode, AnalyserNode)
- Canvas 2D로 파형, 스펙트럼, 배음 지도를 그립니다.
- 외부 라이브러리 없이 HTML 파일 하나로 되어 있습니다. 글꼴만 Google Fonts에서 불러옵니다.
