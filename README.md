# Sine Garden

사인파를 쌓아 소리를 만들면서 **푸리에 합성**을 배우는 웹 신시사이저입니다.
설치나 빌드 없이 브라우저에서 바로 실행됩니다.

## 기능

- **사인 오실레이터** — 배율, 레벨, 디튠, 위상을 가진 사인파를 여러 개 쌓아 음색을 만듭니다.
- **엔벨로프** — A/B 두 개의 ADSR 엔벨로프를 사인마다 골라 적용합니다.
- **6밴드 EQ** — 주파수 응답 곡선과 실시간 스펙트럼을 함께 봅니다.
- **푸리에 실험실** — 톱니파, 사각파, 삼각파를 사인 N개로 근사하며 깁스 현상과 위상의 역할을 확인합니다.
- **소리 맞히기 미션** — 목표 소리를 듣고 사인을 조합해 유사도 80~90% 이상을 만들면 성공입니다.
  유사도는 배음별 세기(dB) 차이로 계산하며, 위상과 엔벨로프는 채점하지 않습니다.
  진행 기록은 각자의 브라우저에만 저장됩니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 컴퓨터 키보드(흰 건반 A S D F…, 검은 건반 W E T Y U…)나 화면 건반으로 연주합니다.

## 기술

- Web Audio API (OscillatorNode, PeriodicWave, BiquadFilterNode, AnalyserNode)
- Canvas 2D로 파형, 스펙트럼, 배음 지도를 그립니다.
- 외부 라이브러리 없이 HTML 파일 하나로 되어 있습니다. 글꼴만 Google Fonts에서 불러옵니다.
